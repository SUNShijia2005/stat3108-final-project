## 重要范围

### 航班计划

- Cargolux 数据是原始表格的计划记录，**438 条不等于 438 条独立航线，也不等于 438 个已确认的具体日期航班**。不同星期或航班号有多行；同一航班号的起终点组合可能包含经停，不能全部标为直飞。
- 表格写明当地时间。不能直接用两个当地时刻相减当飞行时长，更不能当作门到门送达时效。
- Cargolux 的 Day 列保留原始代码，未展开为具体日期。ANA 的 94 条则来自明确标注 11/1–11/30 的每日列；它们是公布的运营计划，未确认实际执行或剩余舱位。
- ANA 只结构化了四个上海—成田货机航班号，并未将整份 PDF 的客机、代码共享等其他内容都算作已接入。
- PDF 合并的起运地单元格已正确继承。发现 Cargolux 一个原始出发时刻写成 `13:05:`，标准化为 `13:05`，同时保留原始单元格和来源整行供复核。

### 价格与服务

- FedEx 表格为官方公开、有资格条件的费率，**不是任何用户均可享有的无条件零售价，也不是实时成交报价**。账号、付款地、地区、货物和服务覆盖条件需要确认。
- 已提取的 10kg IP 出口参考价例如：E 区 CNY 3,052，F 区 CNY 3,796，1 区 CNY 3,931。表头将澳大利亚列为 E 区主要目的地、德国列为 F 区、美国西部列为 1 区；实际仍按分区表与具体地址核对。
- 上述样本不含燃油附加费、特殊费用和适用税费。不能直接显示为用户的全程最终价格。公开标准/优惠表和货代协议价可能相差很大，不能据此声称找到市场最低价。
- IP/IPE/IE 文件中的体积重按厘米长×宽×高÷5,000 计算；多件取各件实重与体积重较高者再汇总，并按来源的进位规则处理。该除数不能自动推广到所有航空公司或其他服务。
- FDF 专用分区表与费率页均存在“服务未开通”的脚注，**有分区和数字不等于该目的地可以使用该服务**。FDF 的资格与最低计费重量也不能套用小包裹规则。这里没有把 FDF 全部费率转成可售方案。
- FedEx 服务费率属于 FedEx 的运输产品，不能拿来充当 Cargolux 或 ANA 航班的承运报价。比较海运和空运时，需统一货物、起终点与服务范围；无法匹配的费用单列缺项或使用明确标识的模拟参数。
- Cathay 的香港出港燃油费仅为附加费，不能加到其他承运人的费用上。11 月下半月公布值属于未来生效计划，不能提前套用于上半月任务。

### 公告与持续推进

国泰正文称曼谷货站拥堵、人员和运能受限，11 月 7–15 日临时仅接受在 BKK 无需拆板即可放行的 BUP/intact ULD 货物，列出 COL、CRT、FRO、PIL、ACT、AVI、HUM 例外。只有匹配承运人、目的地、日期、货物与收货条件的任务才应触发相应判断，不能泛化为所有航空公司或所有曼谷货物禁运。

该官网正文与燃油表在页面公开的 `__INITIAL_STATE__` JSON 中，可以正常读取；只提取可见 HTML 文本会漏掉这些内容。已验证快照提取，但尚未部署长期后台监测器，也未完成真实货物的自动改订。

## 文件

- `raw/`：8 份 PDF 与官方网页快照。
- `manifest.json`：每次最终下载状态、来源、抓取时间、文件大小、SHA-256；失败项也保留。
- `flight_schedule_rows.json`：438 条 Cargolux 记录，每条带来源页码。
- `ana_dated_flight_samples.json`：94 条上海浦东—成田双向具体日期计划。
- `public_rate_samples.json`：20 个 IP 10kg 进出口分区参考费率。
- `cargo_fuel_surcharges.json`：6 条 Cathay 香港出港燃油附加费。
- `operational_events.json`：1 条已核对的运营事件及适用条件。
- `text/`：PDF 文字层和国泰正文提取，辅助检索，不代替版式核对。
- `validation_results.json`：记录数量、文件签名/校验值与结构检查结果。
- `fetch_sources.py`：普通公开网络下载脚本；`prepare_dataset.py`：从本地资料重新提取 JSON，依赖 pypdf。
