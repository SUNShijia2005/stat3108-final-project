## 先看哪些文件

- `manifest.json`：所有下载尝试的来源、状态、字节数、校验值、页数。
- `source_registry.json`：结构化记录对应的来源索引，同时区分网页读取成功与本地下载成功。
- `ocean_rates.json`：34 条公开运价，含来源、箱型、币种、适用区域、日期、包含项与额外费用。
- `transit_times.json`：54 条标准运输时间，含船公司、服务名、方向和来源页码。
- `local_fee_samples.json`：8 条收费样本，刻意保留电子/人工单证等适用条件。
- `retrieval_pages.jsonl`：50 页官方 PDF 的机器提取文本，可作为资料检索原料。
- `raw/`：下载成功的官方原文；`text/`：按文件提取的文本。

前一批中国、美国资料位于 `../source_discovery/`。

## 已知边界与数据质量

1. **跨国家覆盖已扩展，但不能说全部港口都有完整价格。** 区域费率只保留原文区域范围，没有自动扩展成任意国家/港口的报价。
2. **不同船公司的资料不能相互拼成总价。** 例如 Hapag-Lloyd 的当地费用不能直接加到 ONE 或 CMA CGM 的报价上。
3. **基础费率、包含燃油的 FAK 公告、当地费用分开保存。** 有效日期和包含项必须参与判断，避免重复加费。
4. **Until further notice 不等于保证今天仍可订。** 保留资料日期，尚未做全量后续公告核查。
5. **50 页文本是检索资料，不是已校验的 50 页费率行。** PDF 可能含合并单元格、续页、历史费率、未来费率及条件备注；个别原文件有 PDF 数值格式警告，后续需按表格核查。
6. **本地文件和网页读取分开标注。** CMA CGM 两份费率公告、FAL1 和 MSC 欧洲航线 PDF 在网页工具中可读，但直接下载返回 403；相关样本保留官方 URL。Maersk 经上海中转时间表返回 404，没有使用其数值。
7. 来源文件公开可读；这不表示已经核实其开放再分发许可。公开仓库发布时可优先保留来源链接、获取说明和必要的小规模结构化样本。

## 对项目的意义

现在可将原型定位为“多国海运资料查询、公开费率查询及报价比较 Agent”，并根据数据是否齐全决定能回答到哪一步。课程实验可选数条不同地区的航线，而不必限定上海至洛杉矶。

从这些数据建立全程报价前，仍需为选定航线补齐**同一船公司、同一日期、同一货物和箱型**下的适用价格及费用。
