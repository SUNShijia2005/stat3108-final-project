# Parcel Desk：跨境小包客服任务原型

STAT3108 Applied Deep Learning and AI · 阶段报告 · 2026-11-17

## 研究问题

中国至美国的小包客户需要在多轮咨询中补充包裹信息、比较费用、核对文件并查看物流。本项目研究：把可追溯的资料检索和可执行工具接入客服对话，能否提高整个寄件任务的信息一致性和完成质量？

以完整任务为单位：客户修改重量后，应保留目的地和预算、重算费用、使旧结果失效，并让文件使用同一份需求。评价关注计算正确、缺失信息识别、修改处理、资料引用和工具执行。

## 数据与任务范围

现有资料有 39 份 PDF、106 页，另有网页和结构化记录。当前应用集中使用 FedEx 小包费率、分区、附加费、单证指南和 Ship24 示例。海运及航空货运资料留作扩展参考。

已提取 IPE、IP、IE 各 41 个重量档和 10 个分区，共 1,230 个价格单元；美国使用区 1、区 2。这些单元来自同一套费率表，不是独立货件。程序保留源 PDF SHA-256、页码和日期，将 IP 的 10kg 行与已有十个分区样本逐项核对，并检查代表性原表页面。

知识库有 13 个双语整理片段，覆盖体积重、分区、资格、燃油、住宅和偏远费、单证、物流及承运条件。每条保留来源 URL、日期和范围。当前是人工整理子集，尚未将全部 PDF 自动切分入库。

Ship24 认证和官方模拟运单曾通过真实接口验证，缓存含四个法国事件。应用据此复现查询；该模拟轨迹与中国至美国演示任务无关联。

## 系统实现

Python 标准库提供本地 HTTP 服务，SQLite 保存任务、字段、对话、费用、文件检查和物流结果。六个页面支持填写表单、对话修改、费用明细、CSV 导入、文件预览和任务导出。写入携带版本，拒绝过期请求。

默认流程提取显式重量、尺寸、预算、邮编和部分城市词，再调用工具。可选模型模式使用 Responses API 函数调用：模型提出工具和参数，程序执行，将结构化结果交回模型。工具覆盖需求更新、费用、检索、单证及示例物流，并限制循环轮数。连接失败会注明回退为本地流程。

检索使用英文词和中文字符二元组，计算 BM25 及 TF-IDF 余弦相似度，再用 reciprocal rank fusion 融合排名；另保留关键词基线。当前未使用神经嵌入模型。检索结果可进入模型上下文，界面保留引用。

费用采用十进制运算：体积重为长×宽×高÷5,000，取实重与体积重较高者，向上进位到 0.5kg。按邮编选择美国分区，读取服务费率，单列来源版本入境费及已确认住宅／偏远费。燃油参数为按基础运费计算的情景值，未填写时保留待确认项。

单证核对联系信息、币种、原产地、描述、整数数量、发票与装箱数量、行金额及合计。项目自制 HTML 草稿可打印或由浏览器存成 PDF；HS 编码、进口人及签字供最终核对。

## 已执行实验

运行 `python3 scripts/evaluate.py`。案例由开发者编写；模型传输使用模拟响应，不访问线上模型或真实客户运单。

| 组件 | 测试数 | 通过数 |
| --- | ---: | ---: |
| 费用、范围与重量 | 24 | 24 |
| 单证与 CSV | 11 | 11 |
| 流程、保存及缓存物流 | 9 | 9 |
| 模型请求与函数调用协议 | 3 | 3 |
| 本地 HTTP 接口 | 6 | 6 |
| 合计 | 53 | 53 |

费用锚点来自原表。其他案例覆盖体积重、进位、尺寸、地区、非有限数值、缺字段、ODA 与住宅互斥、预算、截止日、特殊货品、金额和数量冲突、任务持久化、跨来源写入及版本冲突。

18 条中英文检索问题各对应一个预期片段 ID，记录 Top-1/Top-3 命中。

| 方法 | Top-1 | Top-3 |
| --- | ---: | ---: |
| 关键词重合 | 16/18（88.9%） | 18/18（100%） |
| BM25 | 17/18（94.4%） | 18/18（100%） |
| BM25 + TF-IDF 排名融合 | 17/18（94.4%） | 18/18（100%） |

此问题集上 BM25 和混合检索比关键词多命中一个首位结果；混合检索未超过 BM25。问题与知识库一起开发，规模较小，结果用于检查实现，不推断真实客户总体表现。

浏览器实测走通完整演示、10kg 改 8kg、50×40×30cm 按 12kg 计费、单证错误及修正、商业发票草稿、物流、检索和测试页面。

## 模型对比与后续工作

`scripts/compare_models.py` 备有 12 个虚构案例，比较同一模型的基础问答、检索上下文、检索与执行工具三组设置。内容包括费用、需求修改、缺尺寸、截止日、电池、文件错误、示例物流及诱导编造输入。

程序保存回复、执行步骤、最终字段、延迟、模型名及提示词／案例哈希，留出人工评分和备注。当前无可用模型密钥，三组线上实验尚未执行；暂不报告模型准确率、端到端完成率或模型优劣。后续固定模型版本，扩展独立案例，重复采样，评分参数和引用，并区分组件正确率与任务完成率。

真实运单接口已实现但未验证，异常物流及实际地址覆盖需要真实案例。费率为带账户资格条件的公开参考，不能代替当期账户报价；送达日需承运人确认。最终课程结论和展示应在模型实验完成后更新。
