# 基于真实运输资料与工具调用的跨境物流客服助手

STAT3108 Applied Deep Learning and AI · 2026 年秋季

## 一 项目背景与目标

个人客户和小型卖家寄送跨境包裹时，需要确认费用、服务时效、所需文件和物流进度。这些信息分散在收费表、服务说明、单证模板和物流查询页面中，客户需要反复查找并提供相同的信息。

本项目面向中国寄往美国的小包运输场景，开发支持中英文的 AI 物流客服助手。系统接收客户需求，结合官方资料、物流 API 和计算工具，完成需求补充、运费估算、服务比较、单证检查和物流状态解释。客户修改重量或尺寸后，系统更新需求、重新计算，并同步修改相关文件。

## 二 数据来源与当前进展

1. **费率与规则。** 使用已收集的 FedEx 出口费率、分区和附加费资料，整理服务、重量区间、适用条件和生效日期。已提取 IPE、IP、IE 各 41 个重量档、10 个分区，共 1,230 个价格单元，保留来源页码和文件哈希，并实现体积重和适用附加费核算。
2. **单证资料。** 已整理 13 条双语参考片段，并依据官方字段指南制作可编辑、可打印的商业发票和装箱单草稿，支持 CSV 导入和一致性检查。
3. **物流查询。** Ship24 已通过认证检查，并返回官方模拟运单的四个物流节点。示例用于开发和复现实验，后续以可获得的真实运单验证。
4. **测试案例。** 已完成 53 项离线测试及 18 条检索问题，另备 12 个案例供基础问答、检索、检索与工具三组模型实验使用。

本地运输参考集合共有 39 份 PDF、106 页，另有网页快照和结构化记录。航空货运与海运资料作为扩展参考，当前任务选用适用的小包资料。

## 三 系统与课程方法

**多轮追问和结构化输出。** 提取目的地、商品、重量、尺寸、预算和期望送达日期，根据任务追问必要信息，整理成统一字段供查询、计算和文件填写。

**检索增强生成。** 按主题切分官方资料，保留来源、地区、服务类型和生效日期。已实现关键词、BM25，以及 BM25 与词／字符 TF-IDF 排名融合的混合检索，为模型提供上下文。当前为稀疏文本特征，神经嵌入可作为后续比较项。

**工具调用。** 模型请求工具，程序执行并返回结果。工具包括运费估算、Ship24 查询、单证生成与检查、任务保存与更新。运费结果展示计费过程、来源、生效日期、已计入费用和待确认项。

已使用 Python 构建本地网页，以 SQLite 保存任务；六个页面展示对话、费用、物流、单证、资料和测试。模型函数调用接口已实现，未配置模型密钥时使用本地流程并显示运行模式。

## 四 演示

客户输入：“我想从上海寄一箱东西到洛杉矶，重 10 公斤，希望月底前到。”助手补齐商品、尺寸与预算，检索说明，计算和比较费用估算。客户修改重量后，系统重新计算并解释变化。

随后生成商业发票和装箱单草稿，加入一处数量或金额错误，展示识别和修正过程。最后查询运单，展示物流时间线、解释状态并提出后续处理建议。官方模拟运单在界面中标注为示例。

## 五 评价

使用相同模型和固定案例，比较基础问答、加入检索、加入检索与执行工具三种配置。评价计算准确率、资料检索率、工具和参数正确率、单证错误识别率、任务完成率及响应时间。

当前实测为 53/53 项离线测试通过；18 条检索问题的关键词 Top-1 为 16/18，BM25 与混合检索均为 17/18，三种方式 Top-3 均为 18/18。问题用于开发检查；线上模型实验已准备但尚未运行。

分析系统是否追问必要信息、正确处理修改、选择适用资料，以及回答是否与工具结果一致。保存接口响应、查询时间和模型及提示词版本，以复现实验。

## 六 预期成果

成果包括网页、资料库、运费计算和单证检查工具、物流查询模块、测试结果、课程展示、报告和 GitHub 仓库。通过完整客户任务展示多轮交互、结构化输出、RAG、混合检索和工具调用的协作，并分析各模块对任务完成质量的贡献。
