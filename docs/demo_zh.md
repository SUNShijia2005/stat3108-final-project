# Parcel Desk 演示流程

启动：在项目目录运行 `python3 app.py`，打开 http://127.0.0.1:8765。Mac 也可运行 `run_local.command`。本地演示无需新增 API 账号或安装依赖。

## 1. 载入任务（30 秒）

点击「载入完整演示」。上海至洛杉矶 90001，衣物 10kg，30×20×10cm，预算 5,000 CNY。联系人为虚构信息，物流为官方模拟示例。

展示已保存的需求和工具执行步骤。打开「运费估算」：IE 3,879.30、IP 3,950.30、IPE 4,151.30 CNY。小计包括基础运费及来源版本入境处理费，其他待确认项目列在下方。

## 2. 多轮修改（45 秒）

在对话页点击「把重量改成 8kg」。目的地、尺寸和预算保留，参考小计变为 IE 3,167.30、IP 3,226.30、IPE 3,383.30 CNY。

将尺寸改成 50×40×30cm 并保存。体积重 12kg 高于实重 8kg，按 12kg 计费；IE 为 4,267.30 CNY。展示来源页码和计算过程。

## 3. 文件检查与修正（60 秒）

进入「单证检查」，把装箱数量从 2 改成 1，点击检查。系统指出发票 2 件、装箱单 1 件。

改回 2，把合计从 50 改成 60，再检查，展示金额不一致。恢复 50 后通过基础一致性检查。

导出商业发票或装箱单，查看草稿中的重量、尺寸、明细和待核对信息。可打印或用浏览器另存为 PDF。

## 4. 检索与物流（60 秒）

在「运输资料」查「住宅派送费与偏远地区费会重复收吗？」，查看结果和来源；切换关键词、BM25、混合检索。

查看官方模拟运单的四个事件，注明是法国示例轨迹，与上海至洛杉矶任务无关联。无需启用真实查询，不额外消耗包裹额度。

## 5. 测试结果（30 秒）

打开「测试与进展」，展示 53 项离线测试和 18 条检索问题的实际结果。解释当前是本地流程模式，模型接口及三组比较程序已准备，线上模型实验尚未运行。

演示不做实际寄件、不提交海关文件、不消费模型 API 额度。
